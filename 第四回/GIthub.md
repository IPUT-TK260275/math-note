## 1. 逆行列による解き方の復習

次の連立方程式を考える。

```text
2x + 3y = 11
x  -  y = 3
```

係数を行列でまとめる。

```text
[2   3] [x] = [11]
[1  -1] [y]   [ 3]
```

ここで、

```text
A = [2   3]
    [1  -1]

B = [x]
    [y]

C = [11]
    [ 3]
```

とすると、

```text
AB = C
```

である。

両辺に左から `A^-1` をかけると、

```text
B = A^-1 C
```

になる。

今回の例では、

```text
det A = 2(-1) - 3(1)
      = -5
```

したがって、

```text
A^-1 = 1/5 [1   3]
           [1  -2]
```

よって、

```text
B = 1/5 [1   3] [11]
        [1  -2] [ 3]

  = 1/5 [20]
        [ 5]

  = [4]
    [1]
```

答えは、

```text
x = 4
y = 1
```

## 2. 掃き出し法とは

掃き出し法とは、行列の行に対する操作で、左側を単位行列に変形する方法である。

例えば、

```text
[1   2 | 3]
[3  -1 | 2]
```

を行基本操作で

```text
[1   0 | x]
[0   1 | y]
```

の形にできれば、右端から解を読み取れる。

---

## 3. 行基本操作

掃き出し法で使う操作は、主に次の3つである。

### 1. 行を交換する

```text
[1  2]  ->  [3  4]
[3  4]      [1  2]
```

### 2. 行を0でない数倍する

```text
[1  2]  ->  [1  2]
[3  4]      [6  8]
```

### 3. ある行に、別の行の何倍かを足す

```text
[1  2]  ->  [1   2]
[3  4]      [0  -2]
```

---

## 4. 拡大係数行列

連立方程式

```text
x + 2y = 3
3x - y = 2
```

の係数と右辺をまとめると、

```text
[1   2 | 3]
[3  -1 | 2]
```

となる。

これを **拡大係数行列** という。

---

## 5. 2元連立方程式を解く例

```text
x + 2y = 3
3x - y = 2
```

拡大係数行列にする。

```text
[1   2 | 3]
[3  -1 | 2]
```

2行目から1行目の3倍を引く。

```text
R2 <- R2 - 3R1

[1   2 |  3]
[0  -7 | -7]
```

2行目を `-1/7` 倍する。

```text
R2 <- -1/7 R2

[1   2 | 3]
[0   1 | 1]
```

1行目から2行目の2倍を引く。

```text
R1 <- R1 - 2R2

[1   0 | 1]
[0   1 | 1]
```

したがって、

```text
x = 1
y = 1
```

---

## 6. 3元連立方程式も解ける

掃き出し法は、2元だけでなく3元連立方程式にも使える。

```text
x -  y -  z = 1
3x - y + 2z = 4
x - 2y +  z = 0
```

拡大係数行列にして、左側を単位行列に変形する。

最終的に

```text
[1  0  0 |  5/3]
[0  1  0 |  7/9]
[0  0  1 | -1/9]
```

となるので、

```text
x = 5/3
y = 7/9
z = -1/9
```

である。

---

## 今日の最重要まとめ

- 掃き出し法は、行基本操作で連立方程式を解く方法である
- 連立方程式は、係数と右辺をまとめて拡大係数行列にする
- 行基本操作は「行の交換」「行の定数倍」「別の行の定数倍を足す」の3つである
- 左側が単位行列になれば、右側から解を読み取れる
- 掃き出し法は、2元だけでなく3元以上にも使える
