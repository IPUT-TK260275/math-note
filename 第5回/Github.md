## 1. 逆行列の公式の復習

2次正方行列

```text
A = [a  b]
    [c  d]
```

の行列式は、

```text
det A = ad - bc
```

である。

`det A != 0` のとき、

```text
A^-1 = 1 / det A [ d  -b]
                   [-c   a]
```

である。

---

## 2. 公式で逆行列を求める例

```text
A = [3  4]
    [2  3]
```

まず、行列式を求める。

```text
det A = 3 x 3 - 4 x 2
      = 9 - 8
      = 1
```

したがって、

```text
A^-1 = [ 3  -4]
       [-2   3]
```

である。

---

## 3. 掃き出し法で逆行列を求める考え方

掃き出し法で逆行列を求めるときは、左に `A`、右に単位行列 `E` を並べる。

```text
[3  4 | 1  0]
[2  3 | 0  1]
```

左側を単位行列に変形する。

```text
[1  0 |  3  -4]
[0  1 | -2   3]
```

左側が単位行列になったとき、右側が `A^-1` である。

```text
[A | E] -> [E | A^-1]
```

---

## 4. 2次正方行列の逆行列を掃き出し法で求める

```text
A = [3  4]
    [2  3]
```

単位行列を右に並べる。

```text
[3  4 | 1  0]
[2  3 | 0  1]
```

1行目から2行目を引く。

```text
R1 <- R1 - R2

[1  1 | 1  -1]
[2  3 | 0   1]
```

2行目から1行目の2倍を引く。

```text
R2 <- R2 - 2R1

[1  1 |  1  -1]
[0  1 | -2   3]
```

1行目から2行目を引く。

```text
R1 <- R1 - R2

[1  0 |  3  -4]
[0  1 | -2   3]
```

したがって、

```text
A^-1 = [ 3  -4]
       [-2   3]
```

---

## 5. 3次正方行列にも使える

掃き出し法は、3次正方行列にも使える。

```text
A = [ 1   0   0]
    [-3   1   0]
    [ 0  -3   1]
```

右に単位行列を並べて、左側を単位行列にすると、

```text
[1  0  0 | 1  0  0]
[0  1  0 | 3  1  0]
[0  0  1 | 9  3  1]
```

となる。

したがって、

```text
A^-1 = [1  0  0]
       [3  1  0]
       [9  3  1]
```

---

## 6. 階数 rank とは

行列を掃き出し法で階段状に変形したとき、0だけでない行の本数を **階数** または **rank** という。

例えば、

```text
[1  *  *]
[0  1  *]
[0  0  1]
```

のように3段残れば、

```text
rank A = 3
```

である。

一方、

```text
[1  *  *]
[0  1  *]
[0  0  0]
```

なら、

```text
rank A = 2
```

である。

---

## 7. 階数を求める例

```text
A = [ 4  -3]
    [-8   6]
```

2行目に1行目の2倍を足す。

```text
R2 <- R2 + 2R1

[4  -3]
[0   0]
```

0だけでない行は1本なので、

```text
rank A = 1
```

である。

---

## 今日の最重要まとめ

- 掃き出し法で逆行列を求めるときは `[A | E] -> [E | A^-1]`
- 左側を単位行列にできれば、右側が逆行列である
- 掃き出し法は3次以上の行列にも使える
- 階数 rank は、階段状にしたときの0でない行の本数である
- 階数だけを求めるなら、単位行列まで変形しなくてもよい
